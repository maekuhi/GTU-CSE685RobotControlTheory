Contents:

report.mlx : Main project report, including controller designs, simulations, plots, numerical comparisons, and discussion of results.

stabPro.mlx : Stability proof.

robotMatrices.m : Defines the robot inertia matrix \(M(q)\), Coriolis/centripetal matrix \(V_m(q,\dot q)\), and friction matrix \(F_d\).

desiredTrajectory.m : Calculates the desired joint positions, velocities, and accelerations.

computedTorque.m : Implements the computed-torque control law.

robustControl.m : Implement the robust controller with filtered error and a saturation boundary layer.

adaptiveControl.m : Implements the adaptive control law and parameter update rule.

regressorMatrix.m : Constructs the dynamic regressor matrix \(Y\) used by the robust and adaptive controllers.

computedTorqueODE.m : Connects the computed-torque controller and robot dynamics to ode45.

robustODE.m : Connects the robust controller and robot dynamics to ode45.

adaptiveODE.m : Connects the adaptive controller, robot dynamics, and parameter adaptation to ode45.

simulationSignals.m : Recalculates the tracking errors, filtered errors, and control torques from the simulation results.

plotTracking.m : Plots the desired and actual joint trajectories.

simple_results.mat : Stores the numerical comparison results generated by the simulations.
